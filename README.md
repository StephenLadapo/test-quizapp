# Quiz Challenge App

An engaging, browser-based quiz application that tests users on 20 diverse topics including:
- Geography (South African capital, African countries)
- Science (planets, human body, animals)
- Pop culture (Michael Jackson, cricket legends)
- Logic puzzles and riddles
- Sports (FIFA World Cup 2010)

## Features
- ⏱️ Live timer tracking minutes and seconds
- 📊 Real-time score calculation
- 📧 Email results delivery via EmailJS
- 🎨 Modern, responsive design with gradient backgrounds
- ✅ Instant answer validation
- 🔄 Auto-progress to next question

## How It Works
Users answer 20 multiple-choice questions. After completion, they receive their total marks 
(20), obtained score, and percentage. Results can be emailed for record-keeping.
